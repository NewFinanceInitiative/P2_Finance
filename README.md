## P2 Finance & Decentralised Banking

The New Finance Initiative is aiming to develop and deploy the world's first decentralised banking protocol on public
EVM blockchains - P2 Finance & decentralised banking.

### THIS IS AN ON-SITE PRODUCTION 🚀

The New Finance Initiative does not aim to release the very earliest version of P2 Finance until the year 2036.

#### What is P2 All About?

P2 Finance is an economic stakeholder orientated business for domestic and retail consumption of financial agreements
and processing transactions and transfers that enable the transmission of monetary assets in a fashion that supports 
stakeholder capitalism and working retail funds for the application decentralised finance.
